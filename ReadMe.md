# Albino Kath Hound Armor

Game: KOTOR 1
Author: Dodrari Kaan

Version: 1.0.0



When you defeat the Albino Kath Hound on Dantooine, it will drop some of its hide as an item. If you bring this to Kni at the Jedi Enclave, he will be able to turn it into a new Force-resistant light armor.
